```
Squeeze Page → Thank You Page
```
**Use for:** Quick email capture, cold traffic

### 2. Lead Magnet Funnel
```
Lead Magnet Page → Thank You Page (with tripwire)
```
**Use for:** Value-first lead generation

### 3. Quiz Funnel
```
Quiz Intro → Questions (3-5) → Email Gate → Results → Offer
```
**Use for:** Qualified leads, personalization, 80%+ completion

### 4. Product Launch Funnel
```
Opt-in → Sales Page → Order → Upsell → Thank You
```
**Use for:** Course/product launches

```
Registration → Confirmation → Replay → Sales Page
```
**Use for:** Education-to-sale, high-ticket

```
Interest Page → Thank You Page
```
